## Cómo publicarla en Vercel

1. Entra a https://vercel.com
2. Crea una cuenta o inicia sesión.
3. Presiona **Add New Project**.
4. Sube esta carpeta o súbela primero a GitHub.
5. Vercel detectará automáticamente que es un proyecto Vite.
6. Presiona **Deploy**.
7. Al terminar, Vercel te dará un link público parecido a:
   `https://kiinaqua-vercel.vercel.app`

## Cómo probarla en tu computadora

Instala Node.js y ejecuta:

```bash
npm install
npm run dev
```

Luego abre el link local que aparezca en la terminal.

## Nota importante

Esta versión guarda los pedidos en el navegador usando `localStorage`. Para una tienda real con pagos, usuarios y base de datos, habría que conectarla a servicios como Firebase, Supabase, Stripe/Mercado Pago o una base de datos propia.
